CyberGuard Agent — Mac test build (Apple Silicon: M1/M2/M3/M4 or newer)

1. Extract the ZIP and move CyberGuard Agent.app to Applications.
2. Double-click CyberGuard Agent. No Python or Terminal commands are needed.
3. If you see “CyberGuard Agent Not Opened” and “Apple could not verify”,
   click Done, not Move to Trash. For this CyberGuard test download:
   - Open Apple menu > System Settings > Privacy & Security.
   - Scroll to Security and find the notice that CyberGuard Agent was blocked.
   - Click Open Anyway, authenticate if requested, then confirm Open.
   - Keep the app in Applications and open it again if necessary.
   This build is not Apple notarized. Approval is normally needed only the first
   time for this copy; a replacement build may require approval again.
   If Open Anyway is missing, try opening the app again, then return to Settings.
   School-managed Macs may require IT approval. Do not disable Gatekeeper or
   other system security settings. Only approve the team's known test download.
4. Keep the agent window open and click Open CyberGuard Website.
5. Sign in, copy the pairing code from the app, paste it into Device Scanner,
   and click Pair Device. Allow the browser to connect to apps on your device
   if it requests permission. The port should already match the app window.
6. Use Device Scanner or System Guardian. Closing the app stops the agent.

Generate New Code if the code has expired or was already used. Codes last
five minutes. Refreshing the website currently requires pairing again.

This ZIP is for Apple Silicon Macs, not Intel Macs. Startup Applications
management is currently Windows-only. The malware scanner and starting virus
definitions are included. The app updates definitions automatically when online.
No separate ClamAV, Homebrew, or Python installation is needed.

If connection fails, confirm the agent is open and the website's Agent port
matches the port shown in its window. Check browser permission to connect to
apps on this device. The website must include the Mac agent connection update.
